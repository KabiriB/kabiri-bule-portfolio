Methods and professional judgement

Show the work. Name its limitations.

The Bank Marketing case contains actual model fitting and holdout evaluation, not just an invented dashboard. The published summary below makes the analytical logic reviewable.

Statistical baseline

Logistic regression creates an interpretable comparison model. Test ROC-AUC: 0.791.

Nonlinear alternative

Histogram gradient boosting captures more complex patterns. Selected on validation average precision; test ROC-AUC: 0.813.

Probability reliability

Sigmoid calibration was assessed separately, not assumed beneficial. Test Brier: 0.0751 raw versus 0.0755 calibrated.

Leakage controls

Call duration excluded from pre-contact targeting because it would not be known before calling. Other operational feature availability must still be verified.

Out-of-time testing

Chronological stress testing revealed marked performance degradation; the later-period response base rate also changed.

Economics vs causality

The calculator is a decision illustration. Propensity-to-subscribe differs from incremental response caused by an intervention.

Data: UCI Bank Marketing, based on Moro, Cortez & Rita (2014), Decision Support Systems. Test sample n=6,179; overall observed subscribers n=696. This site presents an analytical demonstration, not a deployed bank targeting service.
